# todo-app

This project contains three parts:

- **Server** (Express + TypeScript + MongoDB)
- **Web App** (React + Vite + Ant Design)
- **Mobile App** (React Native + Expo)

---

## Environment Variables

Before running the project, you need to configure environment variables.

1. Go to each project folder (`server/`, `web/`, `mobile/`).
2. Copy `.env.example` to `.env`.
3. Fill in your variables inside `.env`.

## Running the Server (Express API)

```js
cd server
npm install
npm start
```

## Running the Web App (React + Vite)

```js
cd web
npm install
npm run dev
```

## Running the Mobile App (React Native + Expo)

```js
cd mobile
npm install
npm start
```
